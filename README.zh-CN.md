# frame-align

[English](README.md) | **简体中文**

> 先对齐框架，再动手。

`frame-align` 是一个 agent skill，面向能读写文件的编码 agent。在写任何产品代码之前，agent 和用户通过一个可交互的 HTML 页面反复对齐，直到用户认为这个想法的框架成立。agent 用自己的话复述它的理解，提供方向，指出空缺与矛盾，定位难题的关键点；用户用点选和备注回应。

衡量它的标准只有一个：用户是否比不用它时更轻松地完成了对齐。

## 现状

早期设计稿。

- skill 的指令已经写完。
- 页面是预制的，所以在任何模型下看起来都一样。skill 自带一个本地小服务，每轮运行一次：打开页面，等你提交，把提交交给 agent，然后退出。轮与轮之间没有任何进程留着。
- 页面和两个服务脚本已经用示例数据在浏览器里跑过。skill 整体在单个用例上实际跑过，没有发现明显问题；更多用例和不同 agent 上的表现还有待验证。

skill 的指令用中文写成。页面跟随用户使用的语言。

## 为什么

用户带着一个软件想法来的时候，立刻开始实现，往往做出一个双方都以为对方理解了的东西。常见的补救是一长串澄清问题，这又把工作量转到了用户身上。

`frame-align` 想同时避开两种失败：

- **过重**：流程和格式把 agent 框死，不同的想法得到雷同的问题，agent 自己的洞察出不来。
- **过轻**：agent 跳过对齐，或者页面只是把平常的回答换了个皮。

它的办法是固定循环的形状，把循环里的内容留给 agent。一切从轻开始，轻的手段用过仍不够时才加重。

## 它怎么工作

1. **先读后问。** agent 先读它自己能读到的东西，再用自己的话复述用户的需求。
2. **一轮。** agent 探索，把状态写入 `.frame-align/state.js`，然后运行页面命令，页面在 agent 的内置浏览器或你自己的浏览器里打开。用户点选标记、写备注、提交。结果存到 `.frame-align/returns/round-N.txt` 并直接交给正在等待的 agent，它调整后写出下一轮，开着的页面会自己刷新。agent 最多等几分钟；用户过了这段时间才提交，就回对话说一声，页面会自动把结果交上去。
3. **出口。** 框架是否成立由用户决定。先做一次简短的出口检查，列出尚未了结的内容，然后 agent 写出框架文档，默认是 `framework/framework.md`。

skill 只管动手之前的这一段对齐，不管实现阶段。实现中发现框架要改，可以再次调用，在已有的框架上接着改。

### 页面上

- 用户的原话钉在最上，作为目标。只有用户能改。
- 内容按"要用户做什么"分开摆：需要你定的、我告诉你的、我先替你定了的小事。最后一类每条都能收回。
- 每张卡带适用的标记和备注框。标记负责便宜的决定，真正改变方向的内容写在备注里。
- 从第二轮起，有一排可不选的整轮反馈：输出太多、输出太少、太难懂、跑偏了、进度太慢、进度太快。
- 页面随框架长大，首页最轻。
- 外框和组件是固定的：卡片、对比表、带序号的步骤、格子或树形的框架图、说明块。用哪些、按什么顺序、放什么内容由 agent 决定，以数据的形式写出。页面本身不由 agent 来写。
- agent 可以画图。卡片、说明块、框架的各个部分都可以带一张图：一段 SVG，或一段带自己样式和脚本的 HTML。图与页面相互隔离，所以无论模型怎么画，都不会弄坏页面或读到页面里的东西；图在深浅两种主题下都画在浅色纸面上。文字里也可以用代码块放字符画和目录树。
- 结果进文件，不进用户的 prompt。对话留给用户用自己的话说想说的。

### 预设

预设在第一轮定方向，那时 agent 对用户了解最少。反馈越多，预设管得越少。

| 预设 | 用户带来的 | 第一轮 |
|---|---|---|
| 种子 | 一句话，或一个模糊的点子 | 复述，给几条方向。暂不质疑 |
| 骨架 | 整体框架有了，很多地方是空的 | 复述，画出骨架，标出空缺 |
| 体检 | 相对完整的草案 | 复述，再指出最要紧的一两处矛盾或风险 |
| 难点 | 一个卡住的问题 | 复述，说出最可能的关键点和依据，给出最能区分各种可能的那一步验证。不铺开试验矩阵 |

### 把决定权留在用户手里

用户同意 agent 不是问题，用户不再做决定才是。输出长到读不下去、一连串看起来专业的内容被一路放行、agent 定了用户没看见的事，都会造成这种情况。

skill 首先把它当作 agent 输出的问题：少给，把需要决定的和不需要的分开，说用户能判断的话。轻的手段都不管用时，才请用户先说自己的倾向，再看推荐。

它也要求 agent 不讨好、不免责：事实和看法分开；被质疑时去复核，而不是让步或坚持；给出明确的推荐；去核实，而不是加免责声明。

## 页面怎么用

页面会自己打开：agent 有内置浏览器时开在那里，否则开在你自己的浏览器里。对你在意的内容做出回应，然后点**提交**。没有必填项：你没碰的内容，只表示你对它暂时没有意见。

### 页面顶部

| 控件 | 作用 |
|---|---|
| **你的目标** · 修改 | 你的原话，钉作目标。点"修改"重写，再点"完成"。只有你能改。 |
| 目标下方的浅色条 | agent 从你上一轮的反馈里读到了什么、因此改了什么、这一轮要做什么。只读。 |
| **我的理解** · 哪里不对，直接改 | agent 对你需求的复述。不对就直接改写。与上一轮相同时它会折成一行，可以点开。 |
| **你的技术背景** | 只在第一轮出现，可不填。点选符合的经历，或写一句话。 |

### 卡片

每张卡片都有备注框，什么都可以写：理由、纠正、附加条件。文本框会随输入的内容长高，长文本始终完整可见。标记负责便宜的决定，真正改变方向的内容写在备注里。

| 卡片 | 控件 | 效果 |
|---|---|---|
| 需要你定的事 | 点一个选项块，或点对比表某一列下面的**选这个**。再点一次取消。推荐项带标记，理由写在下方。 | 框架里对应的部分变为已确认。 |
| 灵感 | **留着**、**不要**、**多来点** | "留着"让它成为框架的候选部分。"多来点"让下一轮沿这个方向继续。 |
| 建议 | **接受**、**不接受** | "接受"并入框架。"不接受"不并入，并记入日志。 |
| 事实，附有来源 | **不对** | agent 去复核，并报告查到了什么。 |
| 解释 | **还是没懂** | agent 换一种说法再讲。 |
| 多数卡片 | **解释**、**去核实** | "解释"是要它讲清理由。"去核实"是告诉它这一条很关键，要核对依据。 |

"接受"与"不接受"互斥，"留着"与"不要"互斥，其余标记可以同时选。较长的详情会收起一部分，点**展开**查看全部。

### 其他区域

| 控件 | 作用 |
|---|---|
| **还有 N 条没展开** | agent 暂时收起的次要内容，想看就点开。你是否点开会被记录，agent 借此了解你想看多少。 |
| **我先定了的** · 我来定 | agent 自己先定下的小事。对任何一条点"我来定"即可收回，下一轮它会作为需要你定的事回来。 |
| **框架现状** | 先是一条分布条，显示已确认、待定、有分歧各有多少；下面每个部分一个格子。点格子查看内容并写备注。**重开**把已确认的部分变回待定。 |
| **这一轮整体怎么样** | 六个可不选的选项：输出太多、输出太少、太难懂、跑偏了、进度太慢、进度太快。agent 据此调整下一轮。第一轮没有这一排，也没有"下一步"，只有大文本框。 |
| 大文本框 | 上面没有覆盖到的任何内容：疑问、不满、想换的方向。 |
| **下一步** | "再来一轮"继续循环。"灵感够了"让 agent 停止给新方向，转向补全和收敛。"框架成立"进入出口检查。出口检查那一页上，这里换成"确认出口"和"还要再改"，不点就不算确认。 |
| **关于你的观察记录** | agent 观察到的你的工作方式，它据此调整给你的内容。写得不对可以直接改。 |

### 提交

- **提交**把你的回应存到 `.frame-align/returns/round-N.txt`，并交给 agent。底部横条显示"已送达"时，agent 已经在接着做了，你不用回对话；想补充的话随时可以去对话里说。
- 横条显示"已填好，还没送达"时，说明 agent 已经不在等了，通常是因为你看的时间比较长。回到对话里说一声，页面会自动把结果交上去，不用再点一次。
- agent 不在等的时候，页面照样可以看、可以填。
- 页面底部的横条平时显示你已经回应了几张卡片。
- 提交之后不用关页面。下一轮准备好时它会自己刷新。偶尔会多开出一个标签页，这时旧的那个会提示可以关掉，你填过的内容在新的那个里。
- 你填的内容在这一轮结束前会保存在浏览器里，刷新页面不会丢。
- 最底部的**手动复制（备用）**只在保存失败时才需要。

## 安装

把 `frame-align/` 文件夹复制到你的 agent 的 skills 目录。

- **Claude Code**：`~/.claude/skills/frame-align/` 对所有项目生效，或放在某个项目的 `.claude/skills/frame-align/` 下。用 `/frame-align` 调用。
- **其他支持 Agent Skills 的 agent**：放到该 agent 的 skills 目录，按它点名调用 skill 的方式使用。

页面服务需要机器上有 Node.js 或 Python 3，没有其他依赖。它不常驻：只在 agent 等你的这一轮里运行，收到提交就退出，最多等九分钟也会自己退出。它只监听 127.0.0.1，只把状态交给它自己发出的页面，只接受这个页面的提交。同一个项目的地址每次相同，记在 `.frame-align/server.json` 里。agent 每轮运行一次页面命令；它第一次请求运行时选择以后不再询问，之后就不用每轮批准。两种运行时都没有时，页面仍可作为本地文件打开，回传改用保存对话框或复制粘贴。

这个 skill 设计为手动调用。

- `SKILL.md` 带有 `disable-model-invocation: true`，Claude Code 和 Cursor 认这个字段。上传到 claude.ai 或为 Skills API 打包之前要删掉这一行，那里不接受未知的 frontmatter 字段。
- `agents/openai.yaml` 为 Codex 设置了 `allow_implicit_invocation: false`。写法依据 Codex 文档，没有在 Codex 里实测。
- Gemini CLI 没有仅手动的开关，在那里只能靠 description 里的那句话。
